## 🌟 Overview
مشروع متكامل يجمع بين التحليل الإحصائي باستخدام **Python** والعرض التفاعلي باستخدام **Power BI Dashboard**. قمت من خلاله بتنظيف البيانات، إجراء تحليل استكشافي (EDA)، وبناء نموذج تنبؤي للمبيعات.

## 🛠️ Tech Stack
* **Python**: (Pandas for cleaning, Matplotlib/Seaborn for EDA).
* **Machine Learning**: Scikit-Learn (Linear Regression).
* **Visualization**: Power BI.

## 🔍 Key Insights
* تحليل اتجاه المبيعات والأرباح عبر السنوات.
* تحديد المنتجات والفئات الأكثر مبيعاً وربحية.
* قياس دقة نموذج التنبؤ باستخدام مقاييس الـ R2 Score والـ MAE.

## 🚀 How to Run
يمكنك فتح ملف `superstor-analysis.ipynb` مباشرة هنا على GitHub لمشاهدة الكود والنتائج.
