# 📊 Superstore Sales Analysis & Forecasting
📝 Project Overview
هذا المشروع يهدف إلى تحليل بيانات مبيعات "Superstore" باستخدام لغة Python وبناء نموذج تنبؤي للمبيعات المستقبلية، بالإضافة إلى لوحة بيانات تفاعلية (Dashboard) في Power BI.
🛠️ Tools & Technologies
• Python: (Pandas, NumPy) لمعالجة وتنظيف البيانات.
• Visualization: (Matplotlib, Seaborn) للرسوم البيانية.
• Machine Learning: (Scikit-Learn) لبناء نموذج التنبؤ (Linear Regression).
• Business Intelligence: (Power BI) لعرض النتائج بشكل تفاعلي.
🚀 Key Features
1.	Data Cleaning: تنظيف البيانات ومعالجة القيم المفقودة وتحويل التواريخ.
2.	EDA: استكشاف أنماط المبيعات السنوية والشهرية.
3.	Forecasting: التنبؤ بقيمة المبيعات بناءً على البيانات التاريخية.
4.	Dashboard: لوحة بيانات شاملة تلخص أداء المتجر.
📁 Files in this Repository
• superstor-analysis.ipynb: ملف الكود الذي يحتوي على التحليل والنماذج.
• Sample - Superstore Sales (Excel) .csv: ملف البيانات المستخدم في المشروع.
• README.md: شرح تفصيلي للمشروع.
